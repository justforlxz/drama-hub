# ADR-0016：播放直链入库并按过期时间复用

状态：**已接受**（2026-11-06，MKACG-680）

## 背景

0004 删掉了 `episode.play_url` / `play_url_at`，理由写在 `docs/DATA-MODEL.md`
「0003：直链不落库」：1.0 把很久以前存的 URL 当成永久有效，源侧签名过期后整库断链，
而重解析又因为「库里已经有链接」不会被触发。那一次的结论是「直链只在请求时解析」。

请求时解析本身没问题，问题在**每次播放都重新申请**：

- 播放列表每次请求都会为一整块成员（默认 `merge_chunk_size=10`）解析直链
  （`resolveDirects` → `DirectMany`；有批量能力的源是一次页面请求，否则逐集）；
- 分片先到、播放列表还没建好时，每一集的首次生成再各解析一次；
- 也就是说，一个 10 集的合并块，首播是 1 次批量 + 10 次单集解析，之后**每一次播放列表
  请求仍要 1 次页面请求**（合并块被反复打开时请求数不降）。

红果侧页面请求有约 1/10 的概率「200 + 空体 + 挂到超时」（MKACG-677 的实测），
重复申请等于把 502 概率按播放次数放大。

## 决策

直链与解密 key 落库（新表 `episode_stream`），按 `expires_at` 判定复用：

```sql
episode_stream(episode_id, channel, url, key, expires_at, fetched_at, last_ok_at)
PRIMARY KEY (episode_id, channel)
```

1. **缓存优先**：`Resolver.Direct` 先读库；`expires_at > now()` 直接返回，零外呼。
   过期或没有行才解析一次，并把结果连同过期时刻落库。
2. **过期时刻的来源**：插件给了 `Stream.ExpiresAt` 就用它；没给就用
   `fetched_at + stream_url_ttl_sec`（默认 900 秒，可调，即时生效）。
   900 秒的理由：单集 remux 上限 300 秒，一个合并块首播要逐集取流；再短会让同一块
   的后续播放重新申请，再长则超过多数源侧签名的寿命。
3. **单飞**：同一集的并发请求只解析一次，其余等同一份结果（`Direct` 与 `DirectMany`
   共用这套占位）。
4. **失败自愈**：CDN 返回 401/403/404 时，作废**这一集**的直链（不是整部剧），
   重解析一次并重试一次；重解析失败按播放面错误矩阵上报，不静默重试到超时。
   重解析后通道若翻转则上报，不把新通道的字节写进旧通道的缓存键。
5. **确认可用**：探测或转封装成功后写 `last_ok_at`（只作排障信息，不参与过期判定）。
6. **敏感面不变**：URL 与 key 仍然不进日志、不进错误文本、不回显；key 与 URL 同生命周期，
   一起失效一起重取。换 `stream_secret` 不影响本表（分片缓存键与直链都与出流签名无关）。

## 为什么推翻 0004，但不矛盾

0004 防的是「**无过期判定的永久链接**」：存进去就再也不刷新，签名一过期整库断链。
本 ADR 存的每一行都带 `expires_at`，并且有两条独立的失效路径（时间到、CDN 拒绝），
不存在「把旧链接当永久有效」的可能。

被否方案：

- **进程内缓存直链**：重启即失效、多实例不共享，且同样要解决过期与失效，只是把问题
  挪到内存；库已经在，没有必要多一份状态。
- **不存 key 只存 URL**：App 通道的 key 与 URL 一起发放、一起失效，单独存 URL 会在
  复用时拿到没有 key 的密文流（按通道判据会把它当成网页通道）。
- **一次 403 清空整部剧的直链**：一条链接失败不代表同剧其它集失效，清空只会把
  一次 CDN 抖动放大成整剧重解析风暴。

## 后果

- 合并块首播之后的播放列表请求在 TTL 内零上游请求；首播的分片生成也不再重复解析。
- 库内多了一列为敏感数据的表：`url` 带签名、`key` 是内容密钥。两者都只被
  `internal/stream` 与播放面读取，不进任何日志与错误文本；备份与导出需要按敏感数据处理。
- 直链过期时间依赖插件给的 `ExpiresAt` 或全局 TTL；源侧若在 TTL 内提前吊销签名，
  由「CDN 拒绝 → 作废 + 重解析一次」兜住。
- 一个合并块首播仍要逐集取流（10 次），这是分片生成的固有成本，本 ADR 不改变它；
  预取整剧留待 MKACG-681。

## 回退

删除 `episode_stream` 的读取即可回到「每次请求解析」的旧行为：`Resolver.Direct`
去掉缓存分支、`persist` 不再写入，表可以留着（只占空间）或在后续迁移里删掉。
`Invalidate` 与 `touchStream` 变成空操作，播放面行为立即回到 0004 之后的状态。
