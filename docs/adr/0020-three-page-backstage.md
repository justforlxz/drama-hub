# 0020 后台收敛为三页：概览 / 同步 / 设置

- 状态：已接受
- 日期：2026-11-05
- 关联：MKACG-688（实现）、MKACG-675（四页版，被本决策取代）、MKACG-668（媒体库管理）、
  MKACG-683（正在播放）、ADR-0017（后台重做，页面导航部分被取代）、ADR-0002（单二进制、
  无前端构建步骤）

## 背景

ADR-0017 把后台做成「四页 + 一个对象详情页」：概览 / 剧库 / 剧详情 / 分类 / 设置。剧库页
是台账 + 海报墙 + 搜索筛选 + 补录表单，剧详情页给 WebDAV 路径、集分块与播放地址，分类页
负责 Jellyfin 媒体库开关。

v5 界面设计（`drama-hub-UI-design-v5.md`）重新界定了后台的职责：这个服务是「后台管理」，
不是「客户端」。剧目浏览、封面、播放地址这些能力在 WebDAV 与播放面已经存在，管理界面
再实现一遍等于维护两套入口；而真正需要人工干预的两件事——「Jellyfin 到底同没同步成功」
和「配置改没改对」——反而被摊在多个页面里。

## 决策

1. **页面集合收敛为三个**：`/` 概览、`/sync` 同步、`/settings` 设置。导航只有这三项。
2. **删除剧库 `/library`、剧详情 `/library/{id}`、分类 `/categories`**：路由不注册、模板与
   `static/paging.js` 一并删除，访问旧路径一律 **404**（不做重定向）。选 404 而不是重定向：
   页面确实不存在了，重定向到首页会让人以为入口还在；404 让「已移除」可被观察到。
3. **媒体库管理整体搬到 `/sync`**：Jellyfin 连接摘要（最近同步 / 上次结果 / 立即同步）在上，
   托管媒体库列表（库名 / 剧数 / 库状态 / 启用开关）在下。开关直接 `PATCH
   /api/jellyfin/categories`，关闭前用原生 `<dialog>` 二次确认；关掉后的删除时机（下一轮
   周期同步或立即同步）写在页面说明里。
4. **概览只回答「现在怎么样」**：整机状态、内容同步时间线、正在播放。不出现任何媒体库
   列表、开关、同步按钮，也不再有播放源卡片与「立即刷新」。
5. **视觉换成 v5 的浅色 Apple 风**：设计 token 全部落成 `:root` CSS 变量（见
   `docs/DEV-STANDARDS.md`「页面」）；只有浅色，`prefers-color-scheme: dark` 只把
   `color-scheme` 钉回 light；状态用「小圆点 + 文字」；断点 980px（图标侧栏）/ 700px
   （底部三个入口）。
6. **后端 API 与数据模型不动**：`/api/dramas*`、`/api/refresh` 等端点保留，只是管理界面
   不再消费。这样脚本、WebDAV 与播放面都不受影响，也不需要数据迁移。
7. **浏览器端的分类目录名算法必须与服务器一致**：`/sync` 的「N 部短剧」要按
   `internal/vfs` 的 `genreDir`（空分类落「其他」+ 非法字符替换为 `_`）归并，而浏览器拿不到
   那个函数。为避免两处实现静默漂移，`TestGenreDirContract` 直接读 `internal/web/static/app.js`
   与 `internal/vfs/tree.go`，断言替换字符集与兜底名相同。

## 后果

- 管理面更小：三页、约 850 行 JS，没有表格、没有分页、没有海报墙。
- 剧目浏览与补录不再有管理界面入口；要按上游 id 同步一部剧仍需调 `POST /api/dramas`。
  这是有意的取舍，不是遗漏。
- 文档必须与三页保持一致：README 的路由表与「管理界面」章节、`docs/DEV-STANDARDS.md`
  的页面/设计系统章节都按本决策更新，ADR-0017 的页面集合一节标记为被取代。
- `paging.js` 与其 node 单测删除后，e2e 镜像不再需要 nodejs；`TestPagingContract` 一并移除，
  由 `TestGenreDirContract` 接替「前端业务算法有契约测试」这条约束。

## 被否掉的方案

- **保留 `/library` 与 `/categories`，只换皮**：页面数量与信息重复的问题不变，v5 的三页
  导航也放不下；而且剧库页是这次删除里唯一有大量前端逻辑（筛选 / 分页 / 台账）的页面，
  保留它等于继续维护两套剧目视图。
- **旧路径 302 到 `/`**：会让排障的人以为入口仍在，掩盖「页面已删除」这一事实。
- **为「剧数」新增后端字段**：会改动 `/api/jellyfin/categories` 的响应契约，而本单明确不
  改后端接口；改用源码契约测试守住两处算法一致。
