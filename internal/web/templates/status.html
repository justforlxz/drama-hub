Jellyfin 媒体库

一分类一库：每个分类一个库，库根指向 <媒体库根>/<分类>。Jellyfin 只把 库根的直接子目录当剧集 —— 库根挂在挂载根上时，58 个分类会被认成 58 部 Series、剧目录退化成 普通目录（ADR-0012 的实测依据）。库根必须是 Jellyfin 容器内看到的路径。 三项（地址 / API key / 媒体库根）都填上才启用；只增不删：分类消失只报告「孤儿库」，删除必须走 POST /api/jellyfin/libraries 带 {"prune":true}。
